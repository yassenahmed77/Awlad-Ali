# أولاد علي - وجبات وفراخ مشوية (Awlad Ali App)
> **تطبيق ويب وموبايل تقدمي (PWA) فائق السرعة لمنظومة طلبات المطاعم والمحلات مع إشعارات تيليجرام للكاشير ولوحة تحكم حية.**

---

## 🌟 مميزات المنظومة:

### 1. واجهة العميل (Mobile-First Customer Experience)
- **تصميم موبايل أصلي:** مصمم خصيصاً لتجربة شاشة الهاتف مع دعم الأبعاد والتفاعل باللمس وحواف آيفون (`safe-area`).
- **تثبيت التطبيق (PWA):** إمكانية التثبيت على الهاتف بدون الدخول على متاجر التطبيقات بضغطة زر واحدة.
- **تصفح الأقسام والأصناف:**
  - شبكة دائرية للأقسام الرئيسية (8 أقسام رئيسية).
  - شريط تصنيفات أفقي سلس مع الرموز التعبيرية (Emojis).
  - كروت أصناف أفقية مع صورة المنتج والوصف والسعر وزر الإضافة السريع `+`.
- **نافذة تخصيص الصنف (Bottom Sheet):**
  - اختيار الأحجام (صغير / وسط / كبير / عائلي).
  - اختيار الإضافات والصوصات مع حساب السعر الفوري.
  - عداد كميات مع زر الإضافة السريع.
- **سلة الطلبات الذكية:**
  - زر سلة عائم بمنتصف شريط التنقل السفلي مع تأثير حركي نبضي (Bounce) عند إضافة أي صنف.
  - حفظ السلة محلياً في المتصفح (`localStorage`) لمنع أي استهلاك غير ضروري لقواعد البيانات.
- **إتمام الطلب السلس:**
  - خيار استلام من الفرع (روض الفرج) أو دليفري لمناطق شبرا.
  - التحقق التلقائي من صحة أرقام الهواتف المصرية (010, 011, 012, 015).
  - إشعار واتساب فوري وزر متابعة مباشر.

---

### 2. لوحة تحكم الكاشير والإدارة (`/admin`)
- **تنبيه صوتي للكاشير (Live Chime):** رنة مميزة وعالية باستخدام `Web Audio API` مدمجة بدون ملفات صوت خارجية.
- **لوحة متابعة الطلبات (Live Kanban):**
  - تصنيف الطلبات: (طلب جديد 🟡 / جاري التجهيز ⏳ / جاهز للاستلام 📦 / مكتمل ✅ / ملغي ❌).
  - أزرار تحديث الحالة بنقرة واحدة وتحديث متفائل فوري (`Optimistic UI`).
  - زر طباعة الفاتورة الحرارية (80mm Thermal Receipt).
  - زر اتصال مباشر برقم العميل بنقرة واحدة.
- **إدارة التوفر والخلصان (Inventory Toggle):**
  - إمكانية قفل أي منتج بضغطة واحدة ليظهر فوراً كـ "غير متوفر حالياً" لمنع إحراج المحل مع العملاء.
- **مفتاح حالة المحل:** (المحل مفتوح للطلبات / مغلق حالياً).

---

### 3. إشعارات تيليجرام الفورية (Telegram Bot Alert)
- عند تأكيد أي أوردر، يتم إرسال رسالة منسقة بنظام HTML على تيليجرام الكاشير تحتوي على:
  - رقم الأوردر واسم العميل ورقم هاتفه.
  - نوع الاستلام والعنوان بالتفصيل.
  - جميع الأصناف مع الحجم المختار والإضافات.
  - المبلغ الإجمالي المطلوب.

---

### 4. معايير الـ SEO العالمي وسرعة التحميل
- **JSON-LD Schema.org:**
  - سكيمة `Restaurant` و `LocalBusiness` لربط المطعم بمنطقة شبرا مصر ومحطة روض الفرج للظهور في نتائج بحث جوجل المحلية (Google Local Pack).
  - سكيمة `Product` لكل صنف مع سعره وحالته في المخزون وصورته.
- **Sitemap & Robots:**
  - توليد تلقائي لملف `sitemap.xml` و `robots.txt` لأرشفة فورية في Google Search Console.
- **Fluid Clamp Typography & Spacing:**
  - جميع المسافات والخطوط تستخدم معادلات `clamp()` الحديثة لتتكيف تلقائياً مع جميع مقاسات الشاشات دون تكسير التصميم.
